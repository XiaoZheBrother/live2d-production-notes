# 可复制的 AI Agent 任务模板

[返回目录](../README.md) · [起步路线](../docs/13-ai-builder-quickstart.md)

以下是从制作经验提炼的模板，不是对历史对话的逐字转录。替换方括号中的项目内容，并提供有权使用的参考素材。

## 通用任务契约

```text
目标：[这一轮唯一要达到的可见效果]
输入：[已确认底图、分层素材、模型入口、版本]
保留：[五官、肤色、姿态、动作节奏、其他部件]
允许修改：[具体图层、参数、关键形或纹理区域]
交付：[图稿 / 可编辑工程 / 原生运行文件 / 动态预览]
验收：[相机、动作时间点、朝向、背景、全身与近景]

先读取当前素材和工程，区分事实与假设。
如果问题来自绑定或渲染，先修对应原因，再决定是否重画。
修改前留基线；每轮报告实际改动、实际检查和未覆盖内容。
```

## 设计与出图

```text
为角色设计 [日常 / 暗夜] 造型，气质是 [描述]。
保留参考中的脸型、五官比例、辨识性配色与标志。
生成 [数量] 个方向明显不同的全身候选，并说明发型与服装选择。
先给我确认底图；确认后再继续拆层和绑定。
```

## 局部素材精修

```text
只精修 [袖口 / 发尾 / 手部]，保留现有构图、肤色与动作姿态。
新像素限制在指定区域；已确认的手指和脸不能顺带重画。
保持原始裁切与锚点，检查真实 Alpha。
输出原图、候选、最终采用遮罩，以及深浅背景的同尺度对照。
```

## 原生绑定

```text
将确认素材接入原生 Cubism 工程。
先列相关 ArtMesh、父变形器、参数、遮罩和绘制顺序。
只修改 [对象与关键形]，保护待机、闭眼和其他动作。
保存后通过官方 Editor 导出，检查目标 Core 的实际响应。
交付九向与中间值、全开/半闭/闭眼，以及非目标部件差异报告。
```

## 动作与换装

```text
为 [动作] 制作进入、主姿态和返回待机。
保留 [表情、配件、手书接触]，动作节奏为 [描述]。
视线、头身跟随、自然眨眼与发尾物理使用独立时间。
外观状态独立于动作，检查所有专用袖子、混合手部和特殊姿态。
给我可暂停、重播和定格的全身与近景预览。
```

## 接入与验收

```text
在实际网页显示尺寸下接入确认模型。
列明原生模型与宿主的职责，统一预览和产品的渲染实现。
检查资源引用、参数响应、动作端点、外观覆盖和透明背景。
保留同相机同时间的前后对照，记录性能与控制台结果。
同步源工程和运行资产，输出版本清单、回退位置和验证范围。
不要把计划中的检查写成已执行，也不要把本地接入写成已上线。
```
