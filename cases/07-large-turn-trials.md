# 案例：工具越换越多，为什么大幅转头仍没通过

[返回目录](../README.md) · [本轮审计](../docs/15-post-integration-lessons.md)

## 目标与最后决定

目标是保持确认的三角度脸型、五官与肩颈连接，同时让前发、马尾和小绿毛连续转动。2026-10-27 至 30 日的完整头部试验最终未通过。用户要求先暂停大幅转头、恢复稳定待机；材料和失败记录保留。此结论没有否定先前被接受的有限动作或小幅跟随。

## 试验链及可保留部分

| 方法 | 解决了一部分什么 | 为什么没有交付 |
|---|---|---|
| 三角度整头/局部材质交接 | 端点更接近各自底图 | 双发缘、五官重影、颈部交界不连续 |
| 独立生成前后发与隐藏区域 | 得到候选素材 | 各图发束结构、轮廓和归属不一致；旧脸纹理仍带旧发丝 |
| See-through 本机量化推理 | 1024 三视图推理实际跑通 | 重组嘴形、肤色、细边与领口不够保真，隐藏区仍需修补 |
| 原图可见像素回贴 | 静止还原误差降低 | 移动后露出重复笔触；低误差来自回贴，不能归功于自动拆层 |
| RAFT 局部对应、固定拓扑与 UV | 小范围更稳定，减少逆向映射裂边 | 相似发纹误匹配、大角度脸比例变化，后发不是一个可整体扭转的平面 |
| 根部空间曲面、逐束中心线 | 有限采样的发根连续性改善 | 正反面纹理与内外发束仍不对应，整体发型不保真 |
| ARAP 风格保形 | 固定原始纹理，减少任意缩放 | 内侧碎发成为外侧尖齿、发根卷成团；末端仍有有限采样翻折 |
| 单束原生旋转变形器 | 官方导出，选定束 401 个样本无翻折，边长变化很小 | 只证明单束通路；周围整头失败，正常/半速录像是导出前浏览器试验 |
| 发根交叠与反面主束遮挡交接 | 静止头颈环境的一段区域测得主束完全隐藏 | 前发硬折、耳脸残留、发饰与根部体积尚未通过；不是新完整原生导出 |

## 真正的判断分支

先固定一个发束：它的根、尖、内外轮廓和中心线在三个视角是否仍指向同一个对象？若答案不清楚，不应直接增加网格密度或平滑强度。连续数值可以把错误对应变得平滑，却不会让它变成正确解剖或发型。

再移动这一束，观察露出的面皮、耳、后发和衣领是否干净。源图颜色阈值不可靠：白发中的暖反光可能被当皮肤，浅色皮肤也可能被归入头发。独立层必须在曝光状态检查，不能只看回合成。

最后才检查遮挡交接。记录切换区间、具体材质、遮挡物、转出/返回方向和物理输入；在端点保留可见阳性对照。某一束在静止头颈的 401 个位置不可见，只能支持该检查范围，不能支持整个脸、发饰和所有九向/物理组合。

## 证据管理的教训

- 369 个有限几何样本、401 个遮挡样本与零翻折，不等于整头视觉通过。
- 关键形 WebGL 预览、原生身体加候选发层、官方导出的整套模型，是三种不同产物。
- 新素材只看过静态终点时，不能借用旧材质的正常/半速录像。
- 用户调整范围以后，小幅稳定版可交付；没有批准缩小范围时，不得悄悄用小幅掩盖原目标失败。
