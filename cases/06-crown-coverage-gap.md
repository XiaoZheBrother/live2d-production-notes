# 头冠采样全过，发际仍然缺角

[返回目录](../README.md) · [验证方法](../docs/10-validation.md) · [版本证据](../references/night-character-evidence.md)

## 症状与根因

独立暗夜失败动作的头顶出现缺角。源角度原画有完整头发，继承的头部网格覆盖轮廓却裁进了头冠；这是显示覆盖问题，不能直接归为“AI 原画少画了一块”。

v3 添加四片头冠补层，上方缺口有所改善。但补层在源图 y=240～310 提前接回旧裁切边界，下方发际又形成内凹。用户再次指出仍有缺角，说明第一次修复和完成判断都不充分。

## 为什么检查没有发现

v3 的 Alpha 检查只覆盖源图 y=140～230，39 条采样轨迹、10 个姿态，共 390 个样本通过。真正有问题的回接带位于范围之外。

这不是样本数小导致的随机漏检，而是检查区域选错了。把同一上半段采得更密，或再增加许多姿态，也不会自动覆盖下方发际。该结果只能写成“所列上段采样通过”，不能写成“头发缺角已修复”。

## 后续怎么改

v4 移除提前回接，沿源图轮廓延长覆盖到 y=500；y=300 以下使用窄边缘补层，避开脸部和眼睛。原五官顶点、原画纹理及动作曲线保持，修改集中在缺失的显示覆盖。

检查扩大到 y=140～495，145 条轨迹、10 个姿态，共 1450 个 Alpha 样本通过；另有旧网格位置与透明度、动作退出路径的对照。数值与正式导出身份见[证据快照](../references/night-character-evidence.md)。

**截至本次记录，v4 仍不是最终视觉验收通过的产品版本。** 已有官方导出与原生姿态图，浏览器整段动态未完成检查，用户尚未确认最新动态，耳侧继承的少量深色碎边仍单列，未同步产品。

扩大后的轮廓采样仍依赖制作者标注，不是独立证明整张确认原画的所有有效像素都被保留。它改善了已知漏检范围，没有消除所有检查盲区。

## 可复用的排查顺序

1. **确定缺失发生在哪一层。** 固定姿态，对照源图、纹理槽位、网格轮廓、UV、蒙版及实际绘制顺序；源像素存在时先修覆盖。
2. **把问题定位到坐标。** 同时记录源图区域、模型姿态和实际截图，避免只写“检查了头发”。
3. **检查完整交接。** 包含原缺口、补层、回接带、相邻外轮廓；不要只盯最早被指出的那一角。
4. **目标尽量独立。** 从确认原画或独立标注建立期望轮廓，不只复用实现生成的补层形状作为测试目标。
5. **做正向与负向检查。** 应显示的纹理要出现，眼睛、皮肤、背景等保护区也不能被补层误盖。不透明背景同样可能让覆盖统计“通过”。
6. **按版本报告边界。** 写明空间范围、采样密度、姿态、阈值、资源哈希与未测区域；有限采样不是连续全域证明。

负向检查需识别修复层的贡献。脸原本就是不透明的，只看最终合成 Alpha 无法判断它是否被错误头发覆盖，还需层级隔离、颜色或图像对照。
