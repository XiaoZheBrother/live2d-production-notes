# 案例：肘部越修越怪，回到第一版做局部修复

[返回目录](../README.md) · [身体与手部](../docs/04-body-and-hands.md)

## 问题并不是整个动作都要重做

暗夜打招呼的抬手轨迹、比例与袖型已有可接受的第一版，但小臂与大臂连接处有尖角、重叠和接缝。后续改动扩大到整段手臂与袖子，用户反馈更像被扭转，甚至不如第一版。

最终约束变得明确：从第一版恢复，只修肘部多出的轮廓和接缝，保留表情、手臂比例、轨迹与节奏。

## 修复契约

| 类别 | 内容 |
|---|---|
| 先冻结 | 已确认的动作曲线、手部路径、手臂尺度、袖口和整体袖型 |
| 局部处理 | 肘部轮廓、重叠余量、连续袖料与遮挡 |
| 同步检查 | 抬手中段、手腕连接、自然回落与中途退出 |
| 不允许暗中扩大 | 重画整只手、重做肩部姿态、改动作速度 |

保留基线可回退文件，在同一时刻、相机和输入下切换前后版本。全身看是否仍是原动作，肘部近景看尖角是否消除，两者缺一不可。

## 为什么端点检查不够

若一段线在起点为向量 `v`，终点为旋转后的 `Rv`，直接对两个端点做线性插值，其中点为 `(v + Rv) / 2`。在平面旋转夹角为 θ 时，它的长度为原长的 `|cos(θ/2)|`，旋转越大，中间越可能变短。这是几何示例，不是本次所有袖子缺陷的统一根因。

因此应分别检查旋转部分的长度与关节运动、衣料的局部变形和重叠遮挡。原生旋转变形器等方式可以用于围绕关节运动，但是否替换已有实现，仍应由同条件对照决定。不要为了一个尖角重新设计整条运动链。

## 本次证据

历史局部修复报告记录 325 个采样、非目标网格误差为 0、手部路径误差为 0，保留袖料的最大坐标误差约 0.000114 模型像素，另有 177 个退出检查项。它们证明本轮改动较好地限制在目标范围，不能单独证明接缝视觉自然。

用户随后接受这一版并继续设计下一个动作。接受对象是这一版的实际效果，不代表上述参数和拓扑可以直接复制给其他袖型。报告线索见[后续证据快照](../references/night-character-evidence.md)。
