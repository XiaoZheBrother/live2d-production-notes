# 版本与历史验证摘录

[返回目录](../README.md)

这些是制作记录的历史结果，在 2026-10-20 整理时读回核对。不是本公共仓库 CI 执行的模型测试，也不能代表当前所有设备的性能。没有公开原模型，因此不能在这里独立复算全部数值。

## 主要阶段

| 阶段 | 采用结果 | 证据范围 |
|---|---|---|
| 2026-10-15 思考表情诊断 | 先对齐原画，再整理眼眉嘴职责 | 固定姿态参数探测发现新眼图缺少独立响应 |
| 2026-10-17 原生待机 | 小幅九向、独立眼神、头身跟随、发尾驱动 | 441 组姿态数值检查；另有头颈修正回归 |
| 2026-10-17 单主模型 | 九组动作放入统一原生模型 | 仍依赖宿主控制、面部合成与外观配置 |
| 2026-10-18 高清接入 | 同尺寸超采样与 Alpha 一致的缩放合成 | 图集、几何和节奏保持，改善边缘采样 |
| 2026-10-19 崇拜校准 | 共享造型，保留星星眼/嘴/手，再修右眼和白眉 | 711 状态局部检查；同步比较 558 状态 |
| 2026-10-19 暗夜精修 | 连续袖料与九动作统一外观 | 全动作部件覆盖与本地主题联动 |
| 2026-10-20 回日常转场 | 翻页迎晨，透明背景 | 取代早期暖雾回程；正向追光保留 |
| 2026-10-20 马尾层级 | 写回原生，删除网页临时排序 | 900 组新旧姿态比较；顶点不变 |
| 2026-10-20 翻书袖口 | 只改两处既有纹理槽位，同步源工程 | MOC、25 张其他图集和九份动作保持 |

## 不要误读历史快照

- 早期记录写“沿用 FREE，不启用试用”，后续用户已同意并启用官方 PRO 试用。
- 早期高马尾候选能切换，但视觉未获最终采用；之后暗夜高马尾为另一轮设计。
- 最早统一模型包含更多动作专用素材，后续才逐步共享头发、衣身与表情基线。
- 早期回日常暖雾候选被翻页迎晨替代。
- 某次报告的网格数、参数数和纹理数只适用于对应版本。
- 历史全构建通过不代表每次纹理局部修复都重新运行了全构建。

## 环境范围

主要记录使用 Cubism Editor 5.3.04，部分整合阶段使用官方 PRO 试用；MOC 导出目标 SDK 5.0，运行检查使用 Cubism Core 5.1.0。浏览器端有自定义渲染合成与控制层。

最终阶段统计出现 329 个绘制网格、250 个参数和 27 张 2048 图集。这是项目规模的记录，不是建议读者照此扩张模型。图集冗余与渲染性能仍需按目标设备优化。

## 未来如何更新这份记录

新增条目应写版本、实际执行的检查、失败项和通过范围。删除过时结论时保留取代关系，避免读者把旧试验当现行方案。
