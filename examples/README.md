# 独立教学示例

[返回目录](../README.md)

这些小例子从制作经验重新编写，只展示可以独立验证的工程原则。没有包含项目控制器、角色数据、Cubism Core 或完整渲染器。

要求 Node.js 22+，不需要安装依赖：

```bash
node --test examples/*.test.mjs
node examples/manifest.mjs ./examples
```

## runtime-patterns.mjs

- `ActionClock`：真实经过时间推进动作，暂停时停止；动作倍率不传播到其他系统。调用者负责提供有效帧间隔，以及页面隐藏/恢复策略。
- `follow`：固定目标下一阶指数跟随，响应不依赖帧数。动态目标、物理弹簧和模型参数应用不在示例范围。
- `createAppearanceCoordinator`：异步加载完成后校验覆盖并提交；过期请求不能覆盖新选择，失败保留旧外观。生产代码还需实现取消加载、资源释放与持久化。

`runtime-patterns.test.mjs` 检查低帧率、暂停、不同采样频率、缺件、失败和异步乱序。

## manifest.mjs

为指定目录生成按相对路径排序的 SHA-256 清单。跳过符号链接、Git、依赖与缓存目录；不会写回目标目录。它不检查 MOC 内部数据，也不是敏感信息扫描器。

如果需要把输出存成文件，请存到被扫描目录以外，避免下次扫描把旧清单本身算进去。

## 如何接到真实模型

由宿主将动作时钟的输出用于 Motion 参数采样，将未加速帧间隔交给跟随/物理系统；再按明确的参数所有权顺序应用。外观提交函数应在模型资源准备完成后整套更新。

不同宿主参数更新顺序不同，请结合官方 SDK 与自己模型验证。测试通过只说明这些小函数满足其契约。
