# 头颈比例、手部与衣料接缝

[返回目录](../README.md)

## 脖子显长不一定要加宽肩膀

头部与身体分别精修后，导回全身很容易出现头太高、露颈过长。先把模型和底图放到同尺度相机下，比较下巴、颈底、锁骨和领口的位置，再决定改哪一段。

本项目采用头部整体轻微下沉、颈部上端跟随、下端固定在领口的处理。保留已确认的头部尺度和五官，缩短露颈长度。数值只适用于当时的画布，不应直接复制位移像素。

收紧颈部变形器范围也有帮助：一个过大、作用区不明确的变形器，可能在转头插值时拖动不该动的部位。

## 抬起的手为什么会扁

先分清原因：

| 现象 | 优先检查 |
|---|---|
| 静止底图也扁 | 掌心、虎口、指节和透视画法 |
| 底图正常，绑定后扁 | 不等比缩放、剪切、父变形器叠加 |
| 只有动作中段扁 | 关键形插值和腕部挂点轨迹 |
| 全身尚可，近景不自然 | 原素材细节或网格分辨率 |

我们先修挥手和握拳的绑定比例，再由同姿态前后对照决定是否精修底图。这样能避免用重画补偿错误变换。

技术诊断可检查局部二维变换的两轴长度、夹角和行列式。保持面积并不保证形状自然；保持腕部锚点也不保证手指正确，因此还需要近景观察。

## 关节不是两张 PNG 的接点

只把手臂贴在衣身前面，肩部轮廓容易像硬插头。需要同时处理：

- 肩袖与衣身的连续明暗和褶皱；
- 腋下和腕口的重叠余量；
- 抬臂时肩部、胸侧与衣摆的轻微联动；
- 手腕与袖口共用的移动参考；
- 前后遮挡关系。

衣料联动不要让整件衣服跟手臂同幅度摆动。上臂附近响应更明显，离受力点越远越弱，动作停稳后逐渐收敛。

## 一个实用检查流程

1. 固定待机、起手、抬起、中段、回落、待机结束六类姿态。
2. 每个阶段看全身，再看肩袖和腕口。
3. 暂时逐层隐藏相邻部件，区分原画白块、露底和叠层错误。
4. 单独播放身体运动，再恢复头发与手部运动，确定问题归属。
5. 检查两侧背景和九向跟随的边界状态。

本项目倾听动作后来加入收拢视线、上身微前倾、侧头与轻点头，同时保持持书手势。约束手书接触点后，身体与发尾才做小幅跟随，避免“点头了，书却滑走”。

对于明确接触的手与书，接触稳定性通常比额外摆动更重要。
