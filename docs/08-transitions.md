# 日夜双向转场

[返回目录](../README.md)

## 从生硬的光锥到登场叙事

最初的聚光灯像静止的硬三角形。用户想要的是：灯原本不在中央，两侧追光再汇聚到中央光圈，烟雾散去，角色像登场一样稍作停留。

把需求拆成阶段比叠更多特效更有效：

1. 两个固定灯位分别照向左右；
2. 光束目标连续向中央移动；
3. 在烟雾充分遮挡时整套提交外观；
4. 烟雾散开，角色显现；
5. 中央光圈短暂停留，再淡出。

本项目采用的日常到暗夜转场约 3.8 秒。灯位与目标、柔边光束和地面椭圆光斑分别控制，避免整块光锥直接平移。

## 回程可以有不同叙事

暗夜回日常最终采用约 3.4 秒的“翻页迎晨”：书中透光、小书页升起、弯曲大书页遮挡换装、纸页离开并化为光点、暖光停留。

早期回程曾沿用暖光和浅白烟雾；后来被翻页方案替代。整理历史文档时必须标明这一点。

## 页面已经变亮，特效不能留下黑矩形

主题切换后，页面背景可能已是亮色。如果转场 Canvas 又绘制一整块深色底，就会在角色周围留下矩形。

修复是保持特效画布透明，只绘制需要的书页、光和粒子。用白色、深色和有内容的页面背景检查，不要只在黑色舞台上验收。

## 外观提交和动作播放隔离

转场只控制遮挡、特效与外观提交，不应重新触发挥手、翻书等动作。提交点选在遮挡足够的阶段，且整套发型、服装、饰品一起切换。

快速反向点击需要定义策略，例如取消尚未提交的旧请求、从当前实际外观开始新转场，或合并为最新目标。不能只取消画面特效却让旧异步加载随后提交。

最少检查：待机、翻书、挥手、崇拜中双向切换；连续反向请求；资源失败；减少动态效果；转场结束后特效确实退出。书本光源跟随当前可见书本，不应固定在屏幕常量位置。

此类特效属于宿主表现层，不是仅靠 Motion3 文件就能自动获得的效果。
