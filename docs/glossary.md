# 术语表

[返回目录](../README.md)

| 术语 | 本仓库中的含义 |
|---|---|
| ArtMesh / Drawable | 编辑侧的可变形绘制网格 / 运行侧可绘制对象；观察目标应对应到实际对象 |
| 关键形 / Keyform | 参数特定取值时的形状、透明度等状态 |
| 变形器 / Deformer | 组织和影响子对象形变或旋转的控制结构 |
| 九向 | X/Y 三档组合的九个方向，不是九条空间轴 |
| UV | 网格顶点在纹理中的采样坐标 |
| 图集 / Atlas | 将多个部件装入一张纹理的排版 |
| 配准 / Registration | 把新素材与既有画布、锚点或 UV 对齐 |
| 挂点 / Anchor | 维持手腕、领口或饰品附着关系的参考位置 |
| Premultiplied alpha | RGB 已乘 Alpha 的表示；必须与采样和混合约定一致 |
| 回归 | 修改后确认目标改善，并检查非目标行为没有变化 |
| 原生绑定 | 参数通过模型自身数据产生网格/透明度等响应 |
| 宿主 | 加载模型、提供输入并绘制的网页、应用或查看器 |
| 墙钟时间 | 实际经过时间；动作暂停时应扣除暂停区间 |
| 外观原子提交 | 发型、服装和饰品准备完成后整套切换 |
| 高清 | 本项目指相同显示尺寸下采样质量改善，不等于原画分辨率凭空增加 |
