# 拆层、补全与局部精修

[返回目录](../README.md)

## 拆层由动作决定

单张插画只画出当前可见区域。转头后耳后、发根、脸侧会露出；抬手后肩袖交界会变；翻页时腕口与书缘会改变遮挡。直接沿可见边缘裁切，静态正确也可能一动就缺角。

Live2D 官方的[素材分割说明](https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/)要求考虑可动部件与隐藏部分。项目的落实方式是：先列目标动作与可见性，再决定拆哪里、补哪里。

| 部件 | 常用拆分 | 必须补出的区域 |
|---|---|---|
| 眼睛 | 左右眼皮/睫毛、眼白、虹膜；必要时高光 | 眼皮后方完整虹膜、视线边界余量 |
| 头部 | 脸轮廓、五官、双耳、前发、后发、长发束 | 耳后、颊侧、发根 |
| 手臂 | 肩袖、上臂、肘、小臂、腕口、手掌 | 相邻段的重叠和衣料连续区 |
| 书 | 封面、纸页、托书手、翻页手 | 被手遮挡的书缘、腕口下方 |

不是分得越细越好。每个新增部件都带来蒙版、层级、关键形和换装覆盖成本。

## 统一坐标，再谈“同一张底图”

保存原始画布尺寸、角色中心、基准缩放和图层包围盒。脸部参考图与全身裁切必须能映射回同一坐标系。仅凭“看起来差不多大”配图，会导致脸型、颈长和肩宽关系改变。

局部重绘保留：

1. 输入裁切范围与透明边距；
2. 眼角、手腕等锚点坐标；
3. 原素材和生成候选；
4. 实际采用的局部遮罩；
5. 重新配准后与原图的叠加对照。

## 角度素材与身体机位

明显转脸的原画也需要一组坐标契约：固定身体机位和全身比例，只变头部目标朝向；保留每个角度的脸、眼、鼻嘴、发夹与颈部锚点。先验证正面回合成，再分别验证中间与最终角度。不要逐个缩放五官去凑同一张脸，也不要用自动生成的全图覆盖已确认的嘴形。见[参考角度案例](../cases/04-reference-angle-head.md)。

## 衣料要连着画，再拆回去

暗夜版早期逐段替换袖口，导致上臂、小臂和腕口像不相关的贴片。有效的修法是把相连袖身按源坐标拼起来，统一褶皱、明暗和滚边，再映射回原有部件。

相邻片段不只要颜色相同，褶皱的走势也必须连贯。抬手时腋下受拉、肩部上提、衣身轻微跟随，是结构和运动两方面的问题。

更换书本或持物素材时，先确认原图是否混有托书拇指、腕口和书缘遮挡。它们可能是一个接触组合；只替换“书”的包围盒，会一并删掉不动的手。拆分后必须回合成检查，不能只看书本外观正确。

## 透明图的四类缺陷

- 实际轮廓被切掉：补画缺失内容，不能仅羽化。
- 半透明白边：检查抠图时残留的底色与边缘 RGB。
- 原素材内的异色块：需要局部重绘；改 Alpha 无法修复内部颜色。
- 纹理采样串色：检查图集 padding、采样范围、预乘 Alpha 和相邻槽位。

必须在浅色、深色、棋盘格三种背景上看。绿色是本角色发束和书的合法颜色，不能对整图“见绿就删”。袖口修复使用局部遮罩，并保护皮肤、手指、书和饰品。

透明像素的 RGB 处理要匹配渲染链：预乘 Alpha 数据可以清零全透明像素；直通 Alpha 采样也可能需要边缘扩色。清零不是消除所有黑白边的万能方案。

## AI 局部编辑提示模板

> 只修复指定部位。保持原画裁切、比例、锚点、手势、肤色与线条风格；保护已确认区域。补齐连续衣料和被遮挡轮廓；背景为真实透明通道，不添加光晕、阴影或新装饰。输出仍需配准和回合成检查。

“提示词说了保持”不是保持成功的证据。生成图必须与原图比较，再决定整张采用还是只采用局部。

具体案例见[翻书袖口](../cases/01-book-cuff.md)。
