# 故障速查表

[返回目录](../README.md)

这些是排查优先级，不是仅凭症状就能确定的结论。

| 现象 | 先检查 | 常用修法 | 验收 |
|---|---|---|---|
| 转头脸变扁 | 整体横向缩放、不等比变换 | 分离轮廓、五官、耳和前后发；缩小角度范围 | 九向与中间值的脸宽、眼距 |
| 头只在平移 | 部件是否共用同一位移 | 建立相对透视与遮挡 | 耳、鼻、五官、头发相对运动 |
| 发尾缺角 | 原画裁切、图集槽位、遮罩边界 | 补全隐藏部分与余量 | 最大转头加摆动 |
| 发根折角 | 只移动少量顶点 | 连续渐变权重、降低位移 | 相邻关键形的发束曲线 |
| 眼睛失去甜美感 | 眼裂、虹膜露出、睫毛线重 | 同角度校准五官 | 全脸与近景同时比 |
| 眼睛残缺或漏虹膜 | 眼白余量、Clipping ID | 补全与正确蒙版 | 半闭眼加边界视线 |
| 参数在但不动 | 可见 Drawable 是否绑定 | 探测顶点/透明度响应 | 单参数隔离测试 |
| 口型带动整脸 | 参数职责耦合 | 分离表情与口型控制 | 单独口型和组合表情 |
| 头高、脖子长 | 头颈领口坐标关系 | 头部下沉、颈部过渡 | 同尺度全身底图 |
| 手掌被压扁 | 剪切、不等比缩放、腕点 | 先修绑定比例，再判断原画 | 腕点稳定与掌心近景 |
| 大臂像贴在衣服上 | 明暗断裂、联动不足 | 连续袖料和肩衣身轻联动 | 起手、主姿态、回落 |
| 切动作脸变色 | 原图肤色和脸层合成 | 共享皮肤基线、修合成 | 固定背景逐阶段 |
| 崇拜像另一个造型 | 专用脸/衣服含旧头发 | 复用共用部分，保留特殊眼嘴手 | 崇拜进入与返回 |
| 低帧率时动作越来越慢 | 动作时间被逐帧截断 | 动作按真实时间，物理独立 | 人为掉帧仍按期结束 |
| 加速后眨眼抽搐 | 全局倍率影响全部系统 | 保护眨眼与表情停留 | 自然速度对照 |
| 换装漏袖口或手 | 混合素材、专用姿态 | 全动作部件覆盖表 | 九动作与交接阶段 |
| 快速切换后穿回旧衣服 | 异步请求乱序 | 版本令牌与原子提交 | 慢 A、快 B 竞态 |
| 角色网页里糊 | Canvas/合成缓冲采样不足 | 统一尺寸链并合理超采样 | 同 CSS 尺寸 A/B |
| 书边一圈白 | 抠图底色、半透明蒙版 | 分清素材与合成后局部修 | 深浅背景翻页全流程 |
| 袖口有绿色碎片 | 原图残片是否烘焙进图集 | 局部连续布料修补，保护皮肤 | 同时间近景与图集边界 |
| 马尾压在肩前 | 原生绘制顺序 | 写回源工程并官方导出 | 清除网页临时排序后测 |
| 回日常出现黑矩形 | 特效绘制了不透明底色 | 透明画布仅绘制特效 | 白色和实际页面背景 |
| 预览正常，换宿主不对 | 额外合成/物理/输入未交付 | 写明宿主依赖与参数契约 | 干净宿主加载 |
| 下次导出修复丢了 | 只改运行纹理没改源工程 | 同步源工程与交付清单 | 重开/导出/哈希核对 |
| 侧脸不翻折但眼睛不像 | 多套透视叠加、目标角度超出素材能力 | 明确参数所有权，必要时补角度专用原画 | 同角度五官与所有过渡帧 |
| 转脸时双眼重影或脸透底 | 角度配准、皮肤覆盖、透明度合成 | 对齐眼鼻嘴，重排覆盖和交接时机 | 深浅背景加半闭眼 |
| 垂眸像要睡着 | 用降低眼开度代替视线 | 分开头部姿态、虹膜视线与眼睑 | 实际尺寸的表情可读性 |
| 肘部越修越像扭转 | 是否扩大修改了已确认轨迹和袖型 | 回退到确认基线，只修局部轮廓与遮挡 | 手路径差异及中段近景 |
| 换书后不动的手穿模 | 替换素材是否抹掉托书手与腕口 | 恢复手书接触组合并校准层级 | 抬书到放回的全过程 |
| 中途退出才拉脸 | 同时淡出是否越过参数支持域 | 从当前状态按依赖顺序返回 | 所有允许退出位置加眨眼 |
| 暗夜动作仍像日常 | 是否只换装或减速，语义主体是否清楚 | 独立设计角色表演与动作映射 | 全身可读的分镜和动态 |
| Editor 卡在载入 | 对应日志、字段类型、引用及资源压力 | 按证据修数据或处理资源，再重试 | 成功载入、保存、导出记录 |
| 最终候选缺少动态证据 | 检查是否对应同一导出与控制器 | 固定版本后补验，记录未覆盖项 | 不借用旧版报告宣称通过 |

遇到新问题时，用[复盘模板](../templates/incident.md)记录实际证据，避免把猜测写成根因。
